# Personalized AI Chatbot

## Project Overview

This project is a Personalized AI Chatbot developed using **Python**, **Flask**, **HTML**, **CSS**, and **JavaScript**. The chatbot provides responses to user queries using predefined intents and serves them through a simple web interface.

---

## Features

- Interactive chatbot interface
- Flask backend
- JSON-based responses
- Responsive UI
- REST API endpoint
- Easy deployment on Render

---

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
